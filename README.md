# CYS Class

Cybersecurity class lectures as interactive slide decks.

- **Lecture 01:** The 50 Most-Used Linux Commands (`linux-50-commands/`)
- **Lecture 02:** SIEM Tools: Splunk, Wazuh & more (`siem-tools/`)

To rebuild a deck, run `python3 build.py` inside its folder. The slideshow and terminal simulator shared by all lectures live in `shared/`.
